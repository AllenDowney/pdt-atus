# pdt-atus

Metadata for the [American Time Use Survey (ATUS)](https://www.bls.gov/tus/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** a slice of BLS's 2003–2025 multi-year files: 641 records in four tables, and the activity coding lexicon as three shared code lists. Built locally; the terms are decided (everything ships), but nothing is published yet.

## What the dataset is

BLS's survey of how Americans aged 15 and over spend their time, from a 24-hour time diary, conducted by the Census Bureau since 2003 with households leaving the Current Population Survey. One release, the 2003–2025 multi-year files; the wave is the diary year (TUYEAR).

| Table | Rows | Records | What |
|---|---|---|---|
| `respondent` | 258,954 | 15 | weights, labor force, earnings, time alone and with others, eldercare |
| `summary` | 258,954 | 456 | demographics, diary day, and minutes on each of the 431 activity codes (t010101 … t509989) |
| `activity` | 4,994,172 | 9 | one row per diary activity: its code (TRCODEP and its tiers), duration, times and place |
| `replicates` | 258,954 | 161 | the 160 replicate weights for TUFNWGTP |

The activity codes are the 2003–2025 coding lexicon, stored once in `metadata/code_lists.jsonl` as three lists: 6-digit codes (`atus-lexicon-0325`), second-tier and first-tier categories. TRCODEP, TRTIER2P and TRTIER1P name them. Each summary column t*xxxxxx* is minutes on code *xxxxxx*; its record says which code in `extensions.atus` (see [`EXTENSIONS.md`](EXTENSIONS.md)), and `metadata/groups.jsonl` groups the columns by first-tier category.

For estimates, use the weight and replicates in each table's `design` in [`dataset.yaml`](dataset.yaml): TUFNWGTP for every year but 2020, TU20FWGT for 2020, and 160 replicate weights (Fay's method).

## Terms of use

Allen Downey reviewed the terms on 2026-11-20: the metadata, the documentation and the common-format data ship, with this notice:

> Source: U.S. Bureau of Labor Statistics, American Time Use Survey, 2003-2025 multi-year files. BLS data are in the public domain; BLS asks to be cited as the source.

BLS says what it publishes is in the public domain and asks to be cited as the source (https://www.bls.gov/opub/copyright-information.htm); [`dataset.yaml`](dataset.yaml) quotes it.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum. bls.gov refuses scripts that don't identify a contact, so download them in a browser into `data/raw/2003-2025/` (each source's `manual_steps`).

## How to use the metadata

- `metadata/releases/2003-2025/<table>/variables.jsonl`: one record per variable, with where each fact came from.
- `metadata/code_lists.jsonl`: the activity lexicon; `metadata/groups.jsonl`: activity columns by category.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

BLS asks to be cited as the source: U.S. Bureau of Labor Statistics, American Time Use Survey, 2003–2025 multi-year microdata files, https://www.bls.gov/tus/data/datafiles-0325.htm. Cite this repo by its URL and commit.

## How to rebuild

With the sources in `data/raw/2003-2025/` and a PublicDataToolkit checkout next to this repo (the targets run under a 6 GB memory cap):

```bash
make build
make data      # respondent and replicates; activity and summary wait for batched writing (PublicDataToolkit Task 58)
make views
make check
```
