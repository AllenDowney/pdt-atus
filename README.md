# pdt-atus

Metadata for the [American Time Use Survey (ATUS)](https://www.bls.gov/tus/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

BLS's survey of how Americans aged 15 and over spend their time, from a 24-hour time diary, conducted by the Census Bureau since 2003 with households leaving the Current Population Survey.

## Terms of use

The terms are at https://www.bls.gov/bls/blsterms.htm. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

How to cite the dataset (from the publisher) and this repo.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
